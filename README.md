# АИС Машиностроительного завода

## Быстрый старт

1. Склонируйте репозиторий
   ```bash
   git clone <repository-url>
2. Перейдите в корень проекта
    ```bash
   cd machine-factory
3. Запустите приложение
   ```bash
   docker-compose up --build
   ```
   После этого приложение будет доступно `http://localhost:8888`
   
> Если Docker не установлен на вашей машине, воспользуйтесь официальной <a href="https://docs.docker.com/get-started/get-docker/">документацией</a>.
